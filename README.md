## ✨ Overview

**Student Grade Tracker** is a Java console application developed as part of the **CodeAlpha Java Programming Internship**.

The application allows users to add student records, store marks for multiple subjects, calculate academic performance, and generate a clear student report.

---

## 🚀 Features

- 👨‍🎓 Add multiple students
- 📝 Store marks for multiple subjects
- 📊 Calculate average marks
- ⬆️ Find highest marks
- ⬇️ Find lowest marks
- 🏆 Automatically calculate grades
- 🔎 Search student details using roll number
- 📋 Display all students in a summary table
- 🛡️ Validate user input

## 📁 Project Structure

```text
CodeAlpha_StudentGradeTracker/
│
├── Student.java
├── GradeTracker.java
├── Main.java
├── README.md
└── .gitignore
```

### 🔹 `Student.java`
Contains the student model and handles:

- Student name
- Roll number
- Subject marks
- Average calculation
- Highest and lowest marks
- Grade calculation

### 🔹 `GradeTracker.java`
Manages student records and displays:

- All students
- Individual student reports
- Summary information

### 🔹 `Main.java`
Contains the main program and console menu:

```text
1. Add Student
2. View All Students
3. View Student Details
4. Exit
```

## ▶️ How to Run

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/CodeAlpha_StudentGradeTracker.git
```

### 2️⃣ Open the project folder

```bash
cd CodeAlpha_StudentGradeTracker
```

### 3️⃣ Compile the Java files

```bash
javac Student.java GradeTracker.java Main.java
```

### 4️⃣ Run the application

```bash
java Main
```
